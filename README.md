## Selected Projects

### 01 / Justick AI
**농산물 가격의 흐름을 학습하는 시계열 예측 시스템**

가락시장 도매가 데이터를 바탕으로 작물별 특성을 반영해 가격을 예측하는 캡스톤 프로젝트입니다.

- **담당:** 데이터 분석 · 머신러닝
- **핵심:** 작물별 예측 모델 적용, LSTM + EWC 기반 지속학습, 1·7·28일 예측
- **기술:** Python · PyTorch · Pandas · Scikit-learn

[프로젝트 살펴보기 →](https://github.com/wjyi0615/Justick_AI)

<br>

### 02 / SyncGaze
**시선 추적 실험을 하나의 웹 흐름으로**

온보딩부터 동의, 캘리브레이션, 훈련, 결과 분석까지 연결하는 웹 기반 시선 추적 프로젝트입니다.

- **핵심:** 단계별 세션 상태 공유, 시선 보정, 결과 시각화와 CSV 내보내기
- **기술:** React · TypeScript · Vite · WebGazer · Firebase

[프로젝트 살펴보기 →](https://github.com/wjyi0615/SyncGaze)

<br>

### 03 / KOSPI200 ETF LAB
**같은 지수를 추종하는 ETF, 데이터로 비교하기**

KOSPI200 ETF 네 종목의 가격 성과와 위험을 공통 거래기간으로 비교하는 Python 리서치 프로젝트입니다.

- **핵심:** 데이터 수집 → 검증 → 지표 계산 → 시각화 → 자동 게시
- **분석:** 가격 수익률 · 변동성 · Sharpe · 최대 낙폭
- **기술:** Python · GitHub Actions · GitHub Pages

[웹사이트 보기 ↗](https://wjyi0615.github.io/KOSPI200-ETF-LAB/) · [코드 살펴보기 →](https://github.com/wjyi0615/KOSPI200-ETF-LAB)

<br>

### 04 / ETF Surf
**처음 만나는 ETF를 이해하고 비교하는 웹사이트**

국내 상장 ETF의 투자 대상과 구조, 위험을 읽고 직접 조건을 골라 비교하는 학습 서비스입니다.

- **핵심:** 주제별 탐색, 상품 검색·필터, 최대 3개 비교, 과거 적립식 시나리오
- **설계:** 자료별 출처·기준일 표시, 미확보 데이터 구분, 모바일 탐색 지원
- **기술:** JavaScript · HTML · CSS · Python · GitHub Actions

[웹사이트 보기 ↗](https://wjyi0615.github.io/etf-surf/) · [코드 살펴보기 →](https://github.com/wjyi0615/etf-surf)
